# 汉诺塔递归逻辑讲解

## 1. 题目回顾

三根柱子 A、B、C。一开始 n 个盘按"大在下、小在上"的顺序摞在 A 柱，要把它们全部搬到 C 柱。规则：

- 一次只能移动一个盘
- 大盘不能压在小盘上面

要求打印出每一步，形如 `A -> B`、`A -> C`。

---

## 2. 递归是什么

递归 = **函数自己调用自己**。

它的威力在于：把一个"大的问题"，拆成"和原问题一模一样的、但更小的问题"。等拆到足够小、小到一眼就能解决时，再一层层退回来，整个大问题就解决了。

汉诺塔天然就是这种结构——"搬 n 个盘"可以拆成"搬 n-1 个盘"。

---

## 3. 汉诺塔怎么拆成三步

先假设：**你已经会搬 n-1 个盘了**。那么搬 n 个盘（从 A 到 C）就只剩三步：

1. 把上面 n-1 个盘，从 **A 搬到 B**（用 C 中转）
2. 把最大的那个盘，从 **A 直接搬到 C**
3. 把 n-1 个盘，从 **B 搬到 C**（用 A 中转）

而"搬 n-1 个盘"这个问题，又可以用**同样的三步**继续往下拆……一直拆到只剩 1 个盘。

这就是递归的核心思路：**用"搬 n-1 个"来定义"搬 n 个"。**

---

## 4. 递归的两个必备要素

任何递归都必须有这两样，缺一不可：

1. **终止条件（base case）**：什么时候不再往下递归了。
   - 汉诺塔里就是 `n == 1`——只剩一个盘，直接搬过去，完事。

2. **递推关系**：怎么用"更小的问题"来表示"当前问题"。
   - 汉诺塔里就是上面那三步。

**如果缺了终止条件，函数会无限调用自己，最后栈溢出崩溃。**

---

## 5. 代码逐行讲解

```cpp
#include <stdio.h>

// 功能：把 n 个盘，从柱子 a 搬到柱子 c，柱子 b 做中转
void hanoi(int n, char a, char b, char c) {
    if (n == 1) {
        // 终止条件：只剩一个盘，直接搬，不再递归
        printf("%c -> %c\n", a, c);
        return;
    }

    // 第一步：把上面 n-1 个盘，从 a 搬到 b（中转柱变成了 c）
    hanoi(n - 1, a, c, b);

    // 第二步：最大的盘，从 a 直接搬到 c
    printf("%c -> %c\n", a, c);

    // 第三步：把 n-1 个盘，从 b 搬到 c（中转柱变成了 a）
    hanoi(n - 1, b, a, c);
}

int main() {
    int n;
    scanf("%d", &n);
    // 初始调用：n 个盘，从 A 搬到 C，B 做中转
    hanoi(n, 'A', 'B', 'C');
    return 0;
}
```

**重点看第二、三步里参数是怎么"轮换"的：**

- 第一次递归：`hanoi(n - 1, a, c, b)` —— 目标柱从 c 换成了 b，中转柱从 b 换成了 c。
- 第二次递归：`hanoi(n - 1, b, a, c)` —— 起点从 a 换成了 b，中转柱从 b 换成了 a。

三个柱子的"角色"在不停地轮换，这正是汉诺塔递归的精髓。

## 6. 用 n = 3 手推一遍

把递归完整展开（缩进表示"往里钻一层"）：

```text
hanoi(3, A, B, C)
├─ hanoi(2, A, C, B)              ← 第一步：搬 2 个到 B
│   ├─ hanoi(1, A, B, C) → A -> C
│   ├─ printf            → A -> B
│   └─ hanoi(1, C, A, B) → C -> B
├─ printf              → A -> C   ← 第二步：最大的盘
└─ hanoi(2, B, A, C)              ← 第三步：搬 2 个到 C
    ├─ hanoi(1, B, C, A) → B -> A
    ├─ printf            → B -> C
    └─ hanoi(1, A, B, C) → A -> C
```

最终输出：

```text
A -> C
A -> B
C -> B
A -> C
B -> A
B -> C
A -> C
```

一共 7 步，正好是 `2³ - 1`。

## 7. 为什么递归能跑通：递归信任

写递归时，**不要试图在脑子里一层层追到底**——那会越想越乱。

正确的姿势是**信任假设**：

> 假设 `hanoi(n-1, ...)` 一定能正确地搬走 n-1 个盘。

在这个假设下，`hanoi(n, ...)` 的三步显然是对的。

然后看最底层：`n == 1` 时，我们确实搬对了（就一个盘，直接搬）。

既然 n=1 对，n=2 就对；n=2 对，n=3 就对……一层层推上去，任意 n 都对。

这在数学上叫**数学归纳法**，是递归正确性的根基。

## 8. 步数为什么是 2ⁿ − 1

设搬 n 个盘需要 `T(n)` 步。看三步拆法：

- 第一步搬 n-1 个：`T(n-1)` 步
- 第二步搬最大的：`1` 步
- 第三步搬 n-1 个：`T(n-1)` 步

所以：

```text
T(n) = 2 × T(n-1) + 1
T(1) = 1
```

解出来就是 `T(n) = 2ⁿ - 1`。

64 个盘就是 `2⁶⁴ - 1` 步，即使一秒搬一步，也要几千亿年——这就是传说里"世界末日"的来源。
